# Portfólio — Pedro Lucas

Esboço institucional em React para apresentar projetos digitais.

## Rodar localmente

```bash
npm install
npm run dev
```

Para gerar a versão de produção:

```bash
npm run build
```

Os projetos exibidos e seus links ficam no início de `src/main.jsx`, no array `projects`.

> O formulário de contato é visual neste esboço; conecte-o ao seu serviço de e-mail, WhatsApp ou backend antes de publicar.
